    推送到手机

    每天定时把日报推到手机；B 站稿件被限流、后台登录过期时立刻提醒。电脑开着、Chrome 在后台运行时才会采集和推送。

    手机装 ntfy App（App Store / Google Play 搜 “ntfy”），点 “+” 订阅这个主题名，服务器用默认的 ntfy.sh。主题名相当于密码：别人知道了就能看到你的推送，所以用随机生成的这串，不要改成好猜的词。

    iPhone 装 Bark，打开后复制示例网址里 api.day.app/ 后面那一串。

    在 Server酱官网用微信扫码登录、关注它的服务号，复制 SendKey（SCT 开头）。消息会出现在微信里。免费版每天有条数限制。

    到日报时间，扩展会把详细数据发到一个单独的 ntfy 主题，这个主题不会推到你手机上。在 Dot 里建一个每天执行的任务，把下面整段指令粘贴进去。指令里的网址相当于密码，知道它的人都能读到你的数据，只交给 Dot。

    在手机上看
    
      
    开启后，电脑每次采集完，会把数据用你设的查看密码加密，存到你 GitHub 账号下的一个私密 Gist。手机打开下面生成的网址、输入查看密码就能看，电脑关机时显示最后一次上传的数据。GitHub 上只有加密后的内容，没有密码解不开；token 和查看密码只存在这台电脑的 Chrome 里，不会上传。
    

      

      
    
        
        
        
    GitHub 网页：右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)。Note 随便写，有效期按需，权限只勾 gist，生成后复制粘贴到这里。
    
      
    

      
    
        
        
        
    手机第一次打开时输入。不要用你其他账号的密码。改了密码后，在手机上点“退出”重新输入即可。
